SECTION 01

AI秘書とは何か／かかる費用

AI秘書は、自分専用の業務アシスタントです。メールや予定のように毎日ちょっとずつ時間を取られる雑務を、まとめて引き受けてもらいます。

AI社員との違い

　AI社員AI秘書
任せる仕事事業の特定の業務自分の身のまわりの雑務全般
例投稿作成、進捗管理、CS対応メール仕分け、予定確認、リサーチ
仕組み同じです。違うのは何を任せるかだけ

完成イメージ

朝起きてチャットを開くと、今日の予定と、返信が必要なメールが何の用件かまで1行でまとまっている。この状態を作ります。自分では何もしていません。寝ている間に動いています。

かかる費用

  • Claude CodeまたはCodexのどちらかを契約していれば、この資料の内容に追加費用はかかりません
  • 一番安いプランで月20ドル前後（為替により変動します。最新は各公式ページで確認してください）
  • 外部ツールとの接続も自動実行も、もともと入っている機能です。新しく買うものはありません
  • この資料の範囲であれば、一番安いプランの枠で足ります。重い調べ物を1日中回すようになったら、その時にプランを上げれば大丈夫です
この資料ではCodexの画面で説明していますが、Claude Codeでも手順はほぼ同じです。呼び方が違うところだけ、その都度書き添えています。
SECTION 02

準備：ツールの導入とフォルダ・ルールファイル

まだ入れていない方へ

Claude CodeとCodexは、どちらもデスクトップアプリが用意されています。公式の手順に沿ってインストールし、契約しているアカウントでログインするところまで済ませてください。

  • Claude Code 公式ページ（Anthropicアカウントでログイン）
  • Codex 公式ページ（OpenAIアカウントでログイン）
インストールで詰まったら、エラー画面をスクリーンショットに撮って、そのままAIに貼って聞いてください。環境ごとの差はAIが埋めてくれます。

1. AI秘書専用のフォルダを作る

MacのFinder、Windowsのエクスプローラーで、いつも使っている場所に「AI秘書」という名前のフォルダを1つ作ります。作ったら、アプリのチャットからそのフォルダを選択してください。

普段使っているフォルダは選ばないでください。関係ないファイルまで読ませると、余計な情報が入った状態で判断することになり、出力の精度が落ちます。見せる場所は最初から分けるのが正解です。

2. ルールファイルを作る

ルールファイルは、AIに毎回守らせることを書いておくファイルです。Claude Codeでは CLAUDE.md、Codexでは AGENTS.md という名前になります。

これも自分で書きません。AIに作ってもらいます。

ルールファイル作成プロンプト
このフォルダで、僕専用のAI秘書として動いてほしいです。
CLAUDE.mdを作ってください。
必要な情報は僕に質問してください。

※ Codexを使っている方は CLAUDE.md を AGENTS.md に置き換えてください。

なぜ質問させるのか

これはゴールシークプロンプトと呼ばれる頼み方です。ゴールだけ伝えて、足りない情報はAIに聞かせます。「どんな仕事をしていますか」「連絡はどのツールを使っていますか」と向こうから聞いてくるので、答えていくだけでファイルができあがります。自分で完璧な指示を書くより圧倒的に早いです。

ルールファイルは短くていい

  • 長すぎると逆に守られなくなります。最初はシンプルで大丈夫です
  • 増えてきたら別ファイルに分けて、ルールファイルからは参照するだけにします
  • 「大事なことはメモに残す」という一文は入れておいてください。SECTION 07の育て方がこれで効きます

なぜフォルダから作るのか

考えるほうはAIがやってくれるので、こちらが用意するのは情報のほうです。賢い頭を借りて、自分の情報やデータは手元に置いておく。こうしておくと出力の精度が上がります。

SECTION 03

MCP連携：Gmail・カレンダー・Slackを繋ぐ

ここが一番大事なところです。今の状態だと、AIはさっき作ったフォルダの中しか見えていません。そこを繋ぐのがMCPです。

MCPとは

ざっくり言うと、AIから外部ツールを扱えるようにする仕組みです。APIの仲間だと思ってもらえれば大丈夫です。GmailやカレンダーをAIが読めるようになります。

昔はAPIキーを発行して設定ファイルに書く必要がありましたが、主要なツールは一覧から選ぶだけで繋がるようになっています。この章では、その一覧にあるものだけを扱います。

接続の手順

  1. アプリの左下から設定を開く
  2. プラグイン（Claude Codeではコネクタ）の欄を開く
  3. 繋げるツールの一覧が出るので、Gmailを選ぶ
  4. 認証の画面が開くので、自分のアカウントで許可を押す
  5. 一覧に戻って、接続済みの表示になっていることを確認する

同じ流れでGoogleカレンダーとSlackも繋ぎます。3つとも数クリックで終わります。

繋がらないときは

エラーが出たら、その画面をスクリーンショットに撮って、そのままAIに聞いてください。

接続トラブル時の聞き方
Gmailのプラグインを接続できないんだけど、どうしたらいい？
（エラー画面のスクリーンショットを添付）

分からないことは全部AIに聞く。これは習慣にしておくと、この先ずっと楽になります。

接続するツールの公式ページ

  • Gmail：メールの読み取りと下書き作成に使います
  • Googleカレンダー：予定の確認と登録に使います
  • Slack：結果の通知先に使います。DiscordやChatworkでも代用できます
SECTION 04

最初の仕事：メールを仕分けて返信下書きまで

繋がったので、さっそく仕事を頼みます。まずは仕分けから。

未読メールの仕分けプロンプト
直近1週間の未読のメールを全部読んで、
「返信が必要」「確認だけ」の2つに分けてください。
返信が必要なものは、何の用件かを1行で教えてください。

メールは読む時間より、確認するまでのハードルや、返信するかどうかの判断のほうが長いです。そこを先に潰してくれるのが効きます。

返信の下書きまで書かせる

返信下書き作成プロンプト
返信が必要なものは、それぞれ返信の下書きを作ってください。
送信はしないでください。足りない情報は私に質問してください。
「送信はしないでください」は必ず入れてください。思ったものと違う返信を勝手に送られたら元も子もありません。指示に書いたうえで、SECTION 08の権限設定でも送信を渡さないようにします。二重で止めておくのが安全です。

「結局全部直すなら自分で書くのと変わらない」と思ったら

0から書くのと、あるものを直すのは全然違います。加えて、直した内容は覚えさせられるので、直す量はだんだん減っていきます。

僕の例で言うと、クライアントとのやりとりは基本LINEで、Gmailには契約しているサービスからの連絡が多く来ます。自分で全部見て返信するのが面倒な領域なので、ここを任せるだけでも効果があります。

口調を寄せていく

  • 過去のやり取りを読ませる
  • 「この人にはタメ口」のように、相手ごとの温度を覚えさせる
  • 詳しい育て方はSECTION 07で扱います
SECTION 05

YouTubeリサーチ：APIキー取得からスキル化まで

ここからは、競合リサーチのように時間が溶ける作業を任せます。ネタが無いのではなく、探す時間が無い。そういう仕事です。

YouTubeはSECTION 03のプラグイン一覧にありません。鍵（APIキー）を自分で1つ取ってくる必要があります。ここだけ手順が多いので、動画では流した部分も含めて全部書いておきます。

STEP 1. YouTube Data APIのキーを取得する

Googleが無料で発行しています。Google Cloud Consoleから取得します。

  1. Google Cloud Consoleを開き、普段YouTubeで使っているGoogleアカウントでログインする
  2. 初回は利用規約の同意画面が出るので、同意して続行する
  3. 画面上部の「プロジェクトを選択」→「新しいプロジェクト」をクリック
  4. プロジェクト名を入れて「作成」（名前は何でも構いません。「YouTube Research」など）
  5. 左メニューの「APIとサービス」→「ライブラリ」を開く
  6. 検索バーに YouTube Data API v3 と入力して検索し、結果をクリック
  7. 「有効にする」をクリック（数秒かかることがあります）
  8. 左メニューの「認証情報」→ 画面上部の「＋認証情報を作成」→「APIキー」を選ぶ
  9. 表示されたキーをコピーする

無料枠について

1日あたりの無料枠がかなり大きく設定されています。個人で企画リサーチに使う程度なら、まず超えません。最新の割り当てはYouTube Data API 公式ドキュメントで確認できます。

STEP 2. .envファイルを作ってキーを入れる

キーの置き場所も、自分で作らずAIに作ってもらいます。

.envファイル作成プロンプト
YouTubeのAPIキーを取得したので、.envファイルを作ってください。

できあがったファイルを開いて、コピーしたAPIキーを貼り付けます。貼るだけです。

APIキーは銀行口座の暗証番号と同じ扱いにしてください。AIのチャット欄に直接貼らない。人に見せない。SNSや公開フォルダに置かない。画面共有や動画に映さない。もし漏れたら、Google Cloud Consoleでキーを再生成すれば古いキーは無効になります。

STEP 3. リサーチを頼む

競合リサーチプロンプト
YouTube Data APIを使って、「AI 副業」で検索して、
直近1ヶ月の動画のうち、チャンネル登録者数の3倍以上再生されているものを、
再生数の多い順に10本出してください。

なぜ「登録者数の3倍以上」なのか。再生数だけで並べると、大きいチャンネルばかりが出てきます。登録者10万人で10万回再生より、登録者1万人で10万回回っている動画のほうが、企画としては跳ねています。見るべきは再生数ではなく倍率です。

STEP 4. 仮説と切り口まで出させる

仮説・切り口の追加プロンプト
それぞれの動画について、なぜ伸びたと思うかの仮説と、
僕のチャンネルで使うならどういう切り口になるかを追加してください。

STEP 5. 流れをスキルにして固定する

ここが一番大事です。うまくいった流れは、毎回説明し直すのではなく固定します。

スキルは、AIに覚えさせる作業の手順書のようなものです。一度入れておくと、毎回説明しなくても同じ品質で動いてくれます。手順書も自分では書きません。

スキル化プロンプト
これまでのやり取りを全部参照して、このタスクをスキル化してください。

これで次からは「リサーチして」の一言で、同じものが出てきます。だからこそ、最初の1回で納得いくまで直しておくのが効きます。

スキル化は、いきなりやらないでください。先にその作業を1回手で通すのが順番です。スキル化は良い流れを固定するための作業なので、固定する流れがまだ無い状態でやっても意味がありません。

検索キーワードを変えるだけで横展開できる

作ったスキルは、検索キーワードを変えるだけで別ジャンルにも使えます。自分の領域のキーワードに差し替えてください。

SECTION 06

自動実行：毎朝、触らないで動かす

ここまでは話しかけたら動く状態でした。ここからは話しかけなくても動くようにします。頼み方は日本語のままです。

定期実行の登録プロンプト
平日の朝7時に、未読メールの仕分けと今日の予定をまとめて、
Slackに送ってください。

裏では、時間が来たら決めた作業を起動するオートメーションという仕組みが動いています。デフォルトで搭載されているので、別途入れるものはありません。

登録したら必ず1回テストする

いきなり毎朝送られる状態にする前に、リハーサルを1回挟みます。

ドライラン（リハーサル）プロンプト
本番と同じ流れで動かして、Slackには送らずに結果だけ見せてください。

これがドライランと呼ばれるものです。出力を確認して問題なければ、そのまま本番運用に入れます。朝7時にセットしたら、絶対に7時に出勤してくれる秘書になります。

1つだけ注意：パソコンが起きている必要があります

この仕組みは自分のパソコンで動いているので、電源が切れていると動きません。スリープでも動きません。

ただし2台目は不要です。スリープさせない設定にすれば1台で足ります。この設定も自分で調べる必要はありません。

スリープ防止の設定プロンプト
パソコンを閉じてもPCをスリープさせない設定をしてください。

OSごとの設定場所が違っても、AIが自分の環境に合わせて進めてくれます。

運用パターン

状況おすすめの運用
家にPCを置いて出られるスリープさせない設定にして開いたままにする
PCを持ち歩く朝の実行が終わってから閉じる
使っていない古いPCがあるそれを置きっぱなしにするのが一番楽です
SECTION 07

育て方：使うほど自分専用になる

普通のチャットは、新しい会話を始めると毎回イチから説明し直しになります。AI秘書はそこが変わります。

やることは1つだけ

やり取りの中で「これ覚えといて」と言うだけです。SECTION 02で作ったルールファイルに「大事なことはメモに残す」と書いてあるので、それが効きます。

覚えさせるプロンプトの例
返信を作るときは、敬語とカジュアルの2パターンを出してください。
これ覚えといて。

フォルダの中にメモが作られます。次に返信を書かせると、何も言わなくても2パターン出てくるようになります。毎回頼まなくてよくなる、というのが育つということです。

覚えさせると効くこと

  • 相手ごとの温度（この取引先は敬語、この人はカジュアル）
  • よく使う言い回し、避けたい表現
  • 返信の型（結論から書く、箇条書きにする、など）
  • 定例の予定や、毎月決まってやること

入れた情報は学習に使われる？

設定で選べます。モデルの改善に使うかどうかの項目があるので、気になる方はオフにしてください。そのうえで、パスワードやAPIキーのような値は送らないルールにしておくのが安全です。

最初から完璧を目指さない

まず70点で作って、使いながら足りないところを足していくほうが早いです。動画で作ったものも70点です。ここから足していけば、どんどん自分専用になります。

SECTION 08

権限とセキュリティの推奨設定

便利さより先に、安全側を決めておきます。自動で動くようになるほど、何かあったときの影響も大きくなるためです。

操作ごとの推奨

操作推奨理由
メールを読む常に許可読むだけなら被害が出ません
下書きを作る常に許可下書きは送信されません
メールを送信する渡さない意図しない相手に届くと取り返しがつきません
予定を登録する毎回確認他の人を巻き込む招待が飛ぶことがあります
チャットに通知する許可でOK自分宛ての通知なら影響が閉じます
ファイルを削除する渡さない戻せません

秘密の値の扱い

  • APIキー、パスワード、アクセストークンはチャット欄に貼らない（.envなどのファイルに置く）
  • 画面共有・録画・配信のときは、キーが映る画面を開かない
  • 公開フォルダやSNSに置かない
  • 漏れた可能性があれば、発行元の管理画面ですぐ再生成する（古いキーは無効になります）

会社のアカウントで使う場合

会社のGoogle Workspaceは、管理者側で外部アプリの接続が制限されていることがあります。まずは個人のアカウントで作って、動く状態を確認してから相談するほうが早いです。

考え方はシンプルです。送信は渡さない。自分以外には反応させない。何かあっても被害が出ない形にしておく。この3つを守っていれば、自動化を進めても怖くありません。
SECTION 09

つまずいた時のチェックリスト

症状別の対処

症状まず確認すること
一覧にツールが出てこないアプリを最新版に更新する。それでも出なければ、そのツールは一覧提供の対象外の可能性があります（SECTION 05のようにキー取得が必要）
認証画面でエラーになるブラウザで対象アカウントにログインしているか。別アカウントで開いていないか
接続したのにメールが読めない接続時の許可画面で、読み取りにチェックが入っていたか。一度削除して繋ぎ直すと直ることが多いです
フォルダの中身を見てくれないチャットで対象フォルダが選択されているか。別のフォルダを見ていないか
ルールファイルが守られない長すぎる可能性があります。要点だけ残して、詳細は別ファイルに分ける
朝になっても動いていないPCがスリープしていないか。電源が入っているか。アプリが起動しているか
APIキーが使えない対象のAPIが「有効」になっているか。キーをコピーし損ねていないか（前後の空白に注意）
同じ品質で出てこないスキル化できているか。できていれば、スキルの中身を直接直せます

それでも分からないとき

一番早いのは、詰まっている画面をスクリーンショットに撮って、そのままAIに貼って聞くことです。環境ごとの差はAIが埋めてくれます。

困ったときの聞き方テンプレート
今こういうことをやろうとしています：（やりたいこと）
この画面でこうなって進めません：（スクリーンショットを添付）
何を確認すればいいか、順番に教えてください。

着手前のチェック

  • AI秘書専用のフォルダを作り、チャットで選択している
  • ルールファイル（CLAUDE.md / AGENTS.md）ができている
  • Gmail・カレンダーが接続済みになっている
  • 送信権限は渡していない
  • APIキーはファイルに置き、チャットに貼っていない
  • 自動実行はドライランで1回確認してから本番にした

次に足していく仕事のアイデア

ここまでで土台はできています。あとは自分の面倒くさい仕事を1つずつ渡していくだけです。

夕方の進捗まとめ

その日に届いたメールと、明日の予定を17時にまとめて通知させる。

ダブルブッキング防止

予定を登録する前にカレンダーを確認させ、重複があれば知らせる。

議事録の保存

打ち合わせの文字起こしを要約して、決定事項とタスクだけ残す。

週次リサーチ便

SECTION 05のスキルを毎週月曜に自動実行して、結果を通知させる。

請求・支払いの確認

決まった件名のメールを拾って、対応が必要なものだけ知らせる。

人物メモの蓄積

やり取りした相手の情報を、フォルダ内に少しずつ貯めていく。

足すときの順番

  1. まず手で1回やって、AIに同じことを手動で頼んでみる
  2. 出力に納得できるまで、その場で直しを入れる
  3. 納得できたらスキル化して固定する
  4. 必要なら定期実行に載せる（ドライランを忘れずに）
この順番を守るだけで、うまくいく確率がかなり上がります。逆に、いきなりスキル化や自動実行から入ると、何が悪いのか分からなくなります。

使い方はシンプルです

まずAI秘書用のフォルダを1つ作って、GmailとカレンダーだけMCPで繋いでください。そこからメールの仕分けを1回動かせば、あとは足していくだけです。最初から完璧を目指さず、70点で動かしながら育てていくのが一番早い進め方です。
